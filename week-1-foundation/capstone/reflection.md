Three Git states:
-Working directory
-Staging area(index)
-Repository(.git foldet)

Important of using Git
-Git helps developers track changes to files, collaborate with others, and restore previous versions
 of a project when needed.

Important of commit messages
-Commit messages explain what changes were made and why, making it easier to understand a project's
 history and collaborate with other developers.
